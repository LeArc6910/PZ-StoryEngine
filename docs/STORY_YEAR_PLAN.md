# 1년짜리 이야기 계획 (2026-10-07, B + C, 나중에 D)

목표: 게임 시간 1년 동안 NPC마다 새 이야기를 계속 접하게 한다.
- **B 큰 이야기 3·4·5장**: 한 줄기로 이어지는 장. 갈래는 장 안에서만 두고, 장이 끝나면 다음 장 하나로 모은다.
- **C 곁가지 이야기**: 3~4장면짜리 짧은 이야기를 NPC마다 5개. 큰 이야기 사이 빈 기간에 상황(계절·신뢰도·다른 NPC)에 맞는 것을 골라 끼운다.
- **D AI 곁가지 (나중)**: 정해 둔 곁가지를 다 쓴 뒤 빈 기간을 AI가 쓴 곁가지로 채운다. 지금부터 형식을 맞춰 둔다.

- 8명이 서로 다른 날 시작하므로 플레이어는 거의 매일 누군가의 새 장면을 본다.

## 공통 규칙

- **장 열기**: 앞 장 결말의 플래그·프로필로 첫 장면을 2~3개 중에서 고르고(`next.when`/`list`), 둘째 장면부터 공통 줄기로 모은다. 공통 줄기 문장은 앞 장 결말과 상관없이 맞는 말만 쓴다.
- **장 길이**: 6~8장면, 부탁 2번(물건·소탕·아는 얼굴), 위기 0~1번, 결말 2개(좋은/나쁜). 5장 결말은 그 NPC의 큰 이야기 마무리.
- **죽음·떠남**: 4장(겨울)에만 1~2명 가능, 5장은 마무리라 원칙적으로 없음.
- **부탁 몰림 방지**: 서버 전체로 동시에 열린 이야기 부탁 최대 2개, 같은 날 새 이야기 부탁 최대 1개(지금은 NPC마다 하나씩만 막음).
- **속도 옵션**: 샌드박스 "이야기 속도"(느림 1.5배 / 보통 / 빠름 0.6배): 장면 일수·장 사이 대기·곁가지 간격에 곱함.

## B. 큰 이야기 3·4·5장 (NPC별 개요)

### 레이 (2장 결말: 애니와 귀가 / 애니를 보냄 / 릴리와 삶 / 릴리가 엄마에게 / 릴리를 잃음 / 떠남)
- **3장 「수확」 (가을)**: 농장 첫 수확. 열기: 애니와 함께 · 릴리와 함께 · 혼자. 약탈자가 곡식을 노린다(소탕) → 지키면 레이가 파이크 교회와 수확을 나눔(관계 +), 못 지키면 겨울 식량이 바닥.
- **4장 「긴 겨울」 (겨울)**: 레이가 폐렴으로 쓰러진다. 애니나 릴리가 있으면 그 아이가 무전을 대신 받는다(목소리가 바뀌는 장면). 닥의 약(물건) → 회복 / 회복 못 하면 레이가 약해진 채 봄을 맞음(나쁜 결말, 죽음은 없음).
- **5장 「새 씨앗」 (봄)**: 레이가 농장을 카운티 공동 농장으로 열지 고민. 위기: 파이크(나눔)·빅(장사)·휘태커(배급 관리) 중 누구와 함께할지 → 결말: 공동 농장이 섬 / 농장을 아이에게 맡기고 레이는 은퇴.

### 케이시 (2장 결말: 자유 라디오 / 지하실 / 토비 남매와 삶 / 토비를 잃음)
- **3장 「낯선 손님」 (가을)**: 군 통신병이라는 남자가 무전실에 묵기를 청한다. 위기: 받아 준다(케이시) / 휘태커가 신원 확인 / 행크가 뒤를 밟음 → 진짜 통신병이면 방송이 커지고, 아이언호스 첩자면 무전실이 털림.
- **4장 「얼어붙은 안테나」 (겨울)**: 눈보라에 안테나가 쓰러짐. 고칠 부품(물건) + 탑 주변 망자(소탕) → 겨울 방송이 이어짐 / 카운티가 한 달 동안 소식 없이 지냄(모든 NPC 사기 -).
- **5장 「카운티 방송」 (봄)**: 케이시가 8명 모두를 잇는 첫 '카운티 회의' 방송을 연다(공용 주파수 특별 장면). 살아 있는 NPC 신뢰도 합으로 성공 판정 → 정기 회의 방송이 생김 / 서로 싸우다 끝남.

### 닥 (2장 결말: 격리실 / 이동 진료소 / 마커스 사건 변형 / 다시 염 / 교회 간호사)
- **3장 「약초 정원」 (가을)**: 약이 바닥나 닥이 약초를 기르기 시작(파이크 텃밭과 연결). 1장의 다리 다친 소년이 조수로 돌아온다. 씨앗·도구(물건) → 약초 정원 / 실패.
- **4장 「겨울 아기」 (겨울)**: 파이크 교회의 피난민이 한겨울에 출산. 위기: 닥이 교회로 간다(물자) / 산모를 진료소로 옮긴다(소탕 길 열기) / 방위대 차량 → 아기 탄생(카운티 잔치, 모든 사기 +) / 비극.
- **5장 「스승」 (봄)**: 닥이 조수를 두 번째 의료인으로 키운다. 시험 같은 마지막 부탁(봉합 도구) → 진료소가 둘이 됨 / 닥이 혼자 남음.

### 파이크 (2장 결말: 작은 마을 / 방위대 캠프 / 빅의 보호 / 문 닫음 / 종을 다시 침 / 깃을 내려놓음)
- **3장 「첫 결혼식」 (가을)**: 피난민 두 사람이 결혼을 원한다. 모든 NPC가 초대받는 잔치(명절 모금 방식) → 결혼식 / 비 오는 날의 조촐한 서약.
- **4장 「도둑」 (겨울)**: 교회 창고에서 음식이 사라진다. 범인은 굶는 아이. 위기: 용서(파이크) / 규율(휘태커) / 아이를 빅에게 일꾼으로(빅) → 각자 다른 겨울.
- **5장 「마을 회의」 (봄)**: 교회 사람들이 지도자를 뽑는다. 파이크가 물러날지 → 마을 회의가 섬 / 파이크가 짐을 다 짊어짐.

### 듀이 (2장 결말: 나룻배 / 사고 / 엔진 판매 / 방주 완성 / 엔진 거치대)
- **3장 「연료」 (가을)**: 카운티 휘발유가 바닥. 듀이가 주유소 저장 탱크를 노린다(소탕) + 펌프 부품(물건) → 연료 확보 / 방주가 멈춤.
- **4장 「눈길 구조」 (겨울)**: 눈에 갇힌 농가 가족 구조 요청. 방주를 몰고 감(이동 중 소탕) → 구조 / 듀이가 차에 깔려 다침(닥 필요, 특기 일시 불가).
- **5장 「정비소 학교」 (봄)**: 듀이가 아이들에게 정비를 가르치며 두 번째 차를 만든다 → 카운티 순환 노선 / 듀이 혼자 버팀.

### 휘태커 (2장에서 살아남은 경우만: 검문소 유지 / 케이시를 믿음 / 탈영병 결말들 / 캠프 방비)
- **3장 「민병대」 (가을)**: 민간인들이 훈련을 청한다. 훈련용 탄약(물건) + 시범 소탕 → 민병대 창설 / 사고로 부상자.
- **4장 「진짜 무전」 (겨울)**: 진짜 군 방송(녹스 요새 집결 명령)이 들린다. 위기: 간다(휘태커) / 남는다(파이크·케이시가 붙잡음) → 떠남(죽음 아닌 떠남 가능) / 남아서 카운티를 지킴.
- **5장 「마지막 경례」 (봄)**: 남았다면 분대를 해산해 마을 경비대로 → 경비대 / 분대가 흩어짐.

### 빅 (2장에서 살아남은 경우만: 교역소 / 패거리 되찾음)
- **3장 「장날」 (가을)**: 콜필드에서 첫 월례 장날. 경비(소탕) + 좌판 물자(물건) → 장날이 자리 잡음 / 난장판.
- **4장 「동생」 (겨울)**: 빅의 동생이 좀비로 떠돈다(아는 얼굴의 좀비) → 빅이 처음으로 무너지는 장면.
- **5장 「보안관」 (봄)**: 파이크의 마을 회의가 빅에게 치안을 맡기려 한다. 위기: 수락 / 거절 / 휘태커와 나눔 → 사람이 바뀐 빅 / 옛날로 돌아간 빅.

### 행크 (2장에서 남은 경우: 등산객 가족 결말들 / 한 겨울 더 남음)
- **3장 「숲의 손님」 (가을)**: 숲에 무언가가 덫을 망가뜨린다. 추적 끝에 굶주린 탈영병(휘태커 이야기와 연결 가능) → 데려온다 / 쏜다.
- **4장 「얼의 아들」 (겨울)**: 죽은 사냥 동료 얼의 아들이 살아 있다는 소식. 눈길 정찰(소탕) → 아들을 데려와 덫을 가르침 / 못 찾음.
- **5장 「숲의 학교」 (봄)**: 행크가 아이들(또는 플레이어)에게 사냥을 가르친다 → '이웃'이라는 말을 남기고 숲에 남음 / 홀로 은둔.

## C. 곁가지 이야기 (NPC마다 5개, 3~4장면)

조건(계절·신뢰도·다른 NPC 상태·세계 변화)이 맞는 것 중 하나를 대기 기간에 시작. 한 NPC에 동시에 하나, 서버 전체로 하루 하나.

| NPC | 곁가지 (조건) |
|---|---|
| 레이 | 길 잃은 개가 따라옴 / 트럭 시절 친구의 무전 / 첫 서리 전 감자 캐기(가을) / 썰매 만들기(겨울, 아이가 있을 때) / 암소 출산(봄) |
| 케이시 | 모스 부호 퀴즈 방송 / 정체불명의 음악 방송 / 생일(누군가 기억해 줌) / 정전 밤의 별 보기(전기 끊김 뒤) / 첫 연애편지 상담 |
| 닥 | 옛 병원 동료의 일기 발견 / 치아 뽑기 / 겨울 독감 예방 접종(겨울) / 정신이 흔들리는 환자 / 휴가(닥이 하루 쉼) |
| 파이크 | 옛 성가대 찬송가집 찾기 / 장례 없이 묻힌 사람들 / 크리스마스 성탄극(겨울·명절) / 무신론자와의 논쟁 / 교회 지붕 수리 |
| 듀이 | 옛 경주용 차 / 고장 난 라디오 수리 의뢰 / 눈 체인 만들기(겨울) / 빅과의 내기 / 정비소 고양이 |
| 휘태커 | 부대 깃발 찾기 / 탈영병 편지 / 사격 대회 / 의무병 시절 기억 / 군번줄 돌려주기 |
| 빅 | 도박판 / 빚 독촉 / 패거리 막내 생일 / 훔친 그림 / 옛 감방 동료 |
| 행크 | 곰 새끼 / 낚시 대회 / 눈 속 발자국(겨울) / 덫에 걸린 사람 / 별자리로 길 찾기 |

+ **함께 나오는 곁가지** 4개(NPC 둘 이상): 카운티 장터 하루, 실종 아이 수색(모두), 레이·파이크 추수 감사 저녁, 듀이·빅 자동차 경주.

## D. AI 곁가지 (나중에, 지금 맞춰 둘 형식)

- **슬롯**: 대기 기간에 쓸 곁가지가 없으면(다 썼거나 조건이 안 맞으면) 브릿지가 있을 때만 AI 곁가지 슬롯을 연다. 없으면 그냥 쉼.
- **게임이 정하는 것**: 부탁 종류(물건·소탕·아는 얼굴·없음), 물건은 `Needs` 표에서, 결말 갈래(성공/실패) 2개, 신뢰도·보상. AI는 줄거리 문장만 쓴다.
- **AI가 쓰는 것**: 제목, 장면 3~4개의 beat(영어, AI용), NPC 대사(그 NPC 말투), 일지 서술(플레이어 입장), 성공/실패 결말 문장. JSON 스키마로 받고 검사.
- **저장**: AI 곁가지는 번역 키가 없으므로 노드에 글을 그대로 저장(`text`·`tale` 필드)하고, 인물 탭은 키가 없으면 저장된 글을 쓴다. → **지금 형식에 반영**: 곁가지 노드도 큰 이야기와 같은 노드 형식, 지나온 장면 기록(`st.path`)에 `tale` 글을 함께 넣을 자리를 둔다.
- **정합성**: AI에 그 NPC의 지금 큰 이야기 장면·지난 결말·다른 NPC 상태를 넘기고, 죽은 사람을 살리거나 큰 사건을 지어내지 않게 제한.

## E. 후임 목소리

NPC는 1장 최악 결말, 형편 고갈, 큰 사건의 열병, 2장 결말, 4장(휘태커)에서 죽거나 떠날 수 있다. 그러면 지금은 채널이
잡음뿐이다. 앞으로는 **5~10일 뒤 그 거점의 다른 사람이 같은 주파수를 이어받는다.**

- **이어받는 것**: 거점·주파수·거래 품목·특기·생활 자원·장기 프로젝트(진행도 유지)는 그대로. 바뀌는 것은 이름·성격·말투·이야기.

## F. 공동 결말 「카운티 회의」 (케이시 5장 + 파이크 5장)

- 케이시(또는 후임 노라)의 방송으로, 파이크(또는 후임 에스더)의 교회에서 여는 첫 카운티 회의. 둘의 5장이 하나의 이야기로
  두 사람 인물 탭에 같이 나온다.
- **열리는 때**: 살아 있는 NPC 대부분(6명 이상)이 4장을 마쳤거나, 첫 NPC가 5장을 마친 지 30일이 지났을 때.
- **안건**: 다른 NPC들의 5장 결과가 회의 안건이 된다 — 레이의 공동 농장, 빅의 보안관, 휘태커의 경비대, 닥의 두 번째 진료소,
  듀이의 순환 노선, 행크의 숲의 학교. 각자의 5장 결말이 회의에서 한 줄씩 보고된다.
- **진행**: 회의 준비 모금(명절 모금 방식) + 회의 날 방해하는 무리 소탕 + 공용 주파수 특별 장면(AI 있으면 참석자들이 차례로 발언).
- **결말**: 살아 있는 NPC 신뢰도 합과 준비 성공 여부로 → "카운티 의회"가 생김(정기 회의 방송, 모든 NPC 사기 +, 이후 D의
  AI 곁가지가 회의 소식을 재료로 씀) / 회의가 다툼으로 끝남(관계 악화, 각자도생).
- 1년 이야기의 마지막 큰 장면. 이후는 곁가지와 D.
