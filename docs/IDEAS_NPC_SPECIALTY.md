# 설계 메모: NPC별 특기 지원 (보류, 2026-09-28)

사용자와 검토만 하고 **아직 구현하지 않은** 설계. 진행하기로 하면 이 문서를 출발점으로 삼는다.
관련: `docs/IDEAS_NPC_WORLD.md` (NPC 생활 상태와 연결하면 자연스러움).

## 결론

가능. 필요한 바닐라 B42 기능이 있고(확인: 아래), 이미 만든 틀을 재사용할 수 있다:
교신 탭 지원 버튼(`ALife.request`), 신뢰도 구간(`ALife.LEVEL_MIN`), 보급 배치(`Quests.create` supply_drop),
지도 마커(`QuestMap`), 클라이언트 쪽 좀비 제어(`HuntClient.lua`), A-Life 연동(`ALife.spawnSquad`, 명령·보호).

바닐라 Lua에서 확인한 함수 (42.20.4 설치본 grep):
- 상처·치료: `setStitched`, `setDeepWounded`, `setBleedingTime`, `setScratched`, `setCut`, `setFractureTime`, `setSplint`,
  `setHaveBullet`/`removeBullet`, `RestoreToFullHealth`
- 차량: `vehicle:transmitPartCondition(part)` (서버, `server/Vehicles/VehicleCommands.lua`), `setEngineFeature`
- 상태(무들): `getStats():get/set/add/remove(CharacterStat.X)` (B42 방식)
- 소음: `addSound(...)` (좀비를 끄는 소리, 바닐라 47곳)
- A-Life: 저격수 행동 `conducts = { "sniper" }` (`ALifeModuleConducts.lua`), 의무병 모듈 `medic`

## 공통 방식

- 교신 탭에 **"특기 지원"** 버튼. NPC마다 효과가 다르고, 신뢰도가 높을수록 강해지며, NPC별 대기 시간.
- **효과는 게임 규칙이, AI는 무전 연기만** ("좋아, 지금부터 내 말 잘 들어" / "3시 방향, 쐈다").
- 기본은 **무전 원격 지원**(A-Life 불필요, 확실). A-Life가 있으면 실제 인물이 와서 하는 연출을 더할 수 있음.

## NPC별 특기

| NPC | 특기 | 방식 | 난이도 / 확인할 것 |
|---|---|---|---|
| 방위대 | **저격 엄호**: 일정 시간 내 주변 좀비를 원거리에서 처치 | 서버가 몇 초마다 25타일 안에서 나를 쫓는 좀비를 골라, 그 좀비를 담당하는 클라이언트에게 처치 지시(추적 무리 제어와 같은 방식). 먼 쪽에서 총성. 처치 수 신뢰도 구간별 5~20발. A-Life가 있으면 실제 저격수를 40타일 옥상에 `hold` 배치 가능 | 중. 좀비 처치 함수(`Kill`/`setHealth`)와 멀티 동기화 확인 필요. 총성이 좀비를 끄는 부수 효과(긴장감으로 활용 가능) |
| 닥(간호사) | **원격 수술**: 무전 지시에 따라 몇 초 치료하면 상처 정리 | 출혈 멈춤, 깊은 상처 봉합, 유리 조각·총알 제거, 골절 회복 앞당김, 통증 감소. 붕대·바늘 같은 재료가 있으면 효과가 더 좋게. **물림 감염은 절대 못 고침**(세계관 원칙). 신뢰도가 높으면 크게 다쳤을 때 먼저 연락 | 하~중. 몸 상태는 본인 클라이언트가 관리 → 서버 명령을 받아 클라이언트에서 적용 |
| 듀이(정비공) | **차량 수리**: 요청하면 1~2게임시간 뒤 와서 수리 | 가까운 차량의 엔진·타이어·배터리 등 부품 상태를 신뢰도에 따라 회복(서버에서 상태 변경 + `transmitPartCondition`). A-Life가 있으면 트럭 타고 도착 연출(`Support.parkCar`와 같은 방식) | 하. 차량은 서버 관리. 없는 부품을 새로 달아 줄지는 결정 필요 |
| 케이시(무전사) | **정찰 정보**: 주변 좀비 밀집 지역·추적 무리·적대 A-Life 무리 위치를 지도에 몇 시간 표시 | 퀘스트 지도 마커 재사용. 모드가 아는 정보만: 추적 무리(`hunts`), A-Life 무리(`ActorRegistry`), 로드된 지역의 좀비 수 | 하. 로드된 지역 밖 좀비는 모름 |
| 레이(트럭 기사) | **긴급 보급**: 음식·물·연료통을 가까운 건물에 바로 배달 | 기존 보급 배치 그대로 | 하 |
| 파이크(목사) | **위로와 기도**: 스트레스·공포·우울 감소, 잠 못 드는 밤을 도움 | `CharacterStat` 수치 조절 | 하. 클라이언트에서 적용 |
| 행크(사냥꾼) | **추적 경보**: 다가오는 추적 무리·적대 무리의 방향과 거리를 미리 알리고 이후 접근 시 경고 (원하면 사냥 고기 배달) | 추적 무리·A-Life 위치 정보 | 하 |
| 빅(약탈단) | **미끼 소음**: 60~80타일 떨어진 곳에 총성·폭음을 내 주변 좀비를 그쪽으로 끌어감 | 바닐라 소음 함수 | 중. 서버에서 소음이 나는지 확인 필요. 끌려간 좀비가 다른 플레이어 쪽으로 갈 수 있음(빅다운 부작용) |

## 주의할 점

- **균형**: 즉시 치료·저격 엄호는 게임을 쉽게 만든다. 추천:
  - NPC별 대기 시간 1~3게임일
  - 신뢰도 조건 (예: 40 이상부터, 구간별로 강해짐)
  - 대가: 신뢰도 조금 소모 / 물건 / 다음 부탁을 꼭 들어줘야 하는 "빚"
  - 지금의 NPC 무장 지원(A-Life, 요청 3일·자동 3일)과 대기 시간을 따로 둘지 같이 쓸지 결정
- **멀티 적용 위치**: 몸 상태·무들 = 본인 클라이언트, 좀비 = 그 좀비를 담당하는 클라이언트(`IsoZombie:getOwnerPlayer`),
  차량·아이템 = 서버. 기능마다 맞추고 인게임 호스트에서 한 번씩 확인.
- **나중 기능과 연결**: "NPC 생활 상태"를 넣으면 방위대 탄약이 바닥이면 저격 불가, 닥의 의약품이 없으면 수술 효과 절반처럼 이어짐.

## 지원 대원 총에 소음기 (검토, 2026-09-29)

A-Life 지원(요청·자동)으로 온 대원의 총을 소음기 단 것처럼. **핵심 효과(좀비·적이 덜 몰림)는 확실히 가능**, 들리는 소리·겉모양은 따로.

근거:
- A-Life는 NPC가 쏠 때 **손에 든 총 인스턴스**의 값을 씀: `ALifeCombatFire.lua` 529~537행 `reportSound` → `getSoundRadius()`/`getSoundVolume()`으로 `addSound`(좀비 끌기, 샌드박스 `FirearmNoiseMultiplier`·실내 0.5배 적용),
  총구 불빛 크기(380행)도 같은 값, A-Life 적 NPC가 총성을 듣는 범위(`ALifeInvestigation.lua` 147행)도 같은 값. 발사음은 `getSwingSound()` 이름을 재생(`Combat.shotSounds`, 347행)
- 무기는 `shell:getPrimaryHandItem()` (A-Life 여러 곳)
- 게임 jar `HandWeapon`에 `setSoundRadius`, `setSoundVolume`, `setSwingSound`, `attachWeaponPart` 있음 (jar 문자열 확인, Lua 노출은 인게임 확인)

| 부분 | 가능 여부 | 방법 / 확인할 것 |
|---|---|---|
| 좀비·적이 덜 몰림 | 확실, 하 | 스폰 직후 대원 총의 소음 반경·크기를 20~30%로. 무기 교체·셸 재생성 시 원래대로 돌아가므로 `ALife.protect`(0.5초) 틱에서 다시 적용. 인게임 호스트는 A-Life 전투가 서버에서 돌아 서버 인스턴스 변경으로 충분 |
| 들리는 총성 | 음원 필요, 중 | 바닐라에 소음 총성 음원 없음 → 그대로 두면 "소리는 큰데 좀비는 안 옴" 어색함. 모드에 자유 이용 음원 + sound 스크립트를 넣고 `setSwingSound`. 볼륨만 줄이는 A-Life `gunshotGain`은 전역이라 부적합 |
| 소음기 모양 | MFS 있을 때만, 확인 필요 | 바닐라 B42에 소음기 부품·모델 없음. MFS(Escape from Kentucky, 3633421539)의 `Gunpart.AACMini7_Silencer` 등(`scripts/Part/Canon.txt`, `MountOn` 총 목록 한정)을 `attachWeaponPart`로 달 수 있음. A-Life NPC가 MFS 총을 드는지, 셸 모델에 부품이 그려지는지 인게임 확인. MFS 소음기의 소음 감소(-50~80%)는 MFS Lua(`EFK_Part_Stat_Set.lua`, 발사음 레이어 `suppressorLayers`)가 플레이어 기준으로 처리 → NPC에 적용될지 불확실하니 수치는 우리가 직접 설정 |

주의:
- 균형: 조용한 지원은 좀비를 덜 끌어 크게 유리 → 방위대처럼 장비 좋은 세력만, 또는 신뢰도 80 이상, 또는 NPC 특기(위 표)로 묶기
- 적 습격대는 기본 미적용. 선택 옵션으로 "소리 없이 다가오는 습격" 가능

## 남은 결정 (진행할 때)

1. 8명 모두 넣을지, 일부만 먼저 넣을지 (추천 시작: 방위대 저격, 닥 수술, 듀이 수리, 케이시 정찰)
2. 사용 조건: 신뢰도 기준과 대가 (없음 / 신뢰도 소모 / 물건 / 빚)
3. A-Life가 있을 때 실제 인물이 와서 하는 연출까지 넣을지
4. 신뢰도가 높을 때 위급하면 자동으로 해 줄지 (예: 닥이 먼저 수술 지시)
